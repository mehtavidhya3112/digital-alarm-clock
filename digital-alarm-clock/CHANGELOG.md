# Changelog

All notable changes to this project are listed here.

## [1.2.0] - 2026-10-07

### Added
- Default sound and a confirmation message when an alarm is set (desktop and website)
- Time until the alarm rings shown in the confirmation
- Two-tone default alarm sound when an alarm goes off
- Website: system notification and phone vibration when an alarm rings

## [1.1.0] - 2026-10-07

### Added
- World time tab on the website with live clocks for 29 cities
- Day label (today, tomorrow, yesterday) and time difference from your own time zone
- Add and remove cities, saved in the browser
- Your detected time zone shown under the main clock

### Changed
- Website now has Alarms and World time tabs

## [1.0.0] - 2026-10-07

### Added
- Python desktop alarm clock with tkinter
- 12-hour and 24-hour display
- Add, turn on or off, and delete alarms, saved in `alarms.json`
- Ringing window with Stop and Snooze
- Web version in `docs/` for GitHub Pages
- Muted green theme
- README, hosting guide, VS Code launch settings
